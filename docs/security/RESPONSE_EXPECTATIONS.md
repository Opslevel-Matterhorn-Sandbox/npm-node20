# Délais de réponse

- Nous accuserons réception de votre signalement sous **3 jours ouvrables**.
- Nous visons à fournir une réponse plus détaillée sous **7 jours ouvrables**, incluant notre évaluation et un calendrier estimé pour un correctif.
- Nous suivons un modèle de **divulgation coordonnée** : nous vous demandons de ne pas divulguer publiquement la vulnérabilité tant que nous n'avons pas publié un correctif ou convenu d'une date de divulgation.
